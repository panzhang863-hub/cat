# 猫猫快追 🐱🐭

一个基于地理位置的多人实时「躲猫猫」小游戏。玩家分成 **猫猫（寻找者）** 和 **鼠鼠（躲藏者）** 两个阵营，在真实地图上你追我躲。

- **猫猫**：使用「查看」技能短暂看到鼠鼠的位置，靠近到一定距离即可抓捕
- **鼠鼠**：躲到时间结束即获胜，越出游戏区域会被自动淘汰

## 技术栈

| 模块 | 技术 |
|------|------|
| 前端 | uni-app（Vue），编译到微信小程序 |
| 后端 | Node.js + Express + ws（WebSocket） |
| 存储 | 纯内存（服务重启后数据清空） |

## 目录结构

```
hide-and-seek/
├── uniapp/          # 前端主工程（uni-app，编译到微信小程序）
│   ├── pages/       # 首页 / 房间 / 配置 / 游戏 / 结算 / 历史
│   ├── utils/       # 服务器地址配置、WebSocket 管理、音效
│   └── static/      # 图片与音效素材
├── server/          # 后端服务
│   ├── app.js       # 入口（HTTP / HTTPS 自适应）
│   ├── routes/      # 房间 / 游戏 / 历史 接口
│   ├── services/    # WebSocket、游戏引擎、内容安全校验
│   ├── store/       # 内存数据存储
│   └── utils/       # 地理计算、房间码生成
└── miniprogram/     # 旧版原生小程序（已废弃，仅作参考）
```

## 快速开始

### 后端

```bash
cd server
npm install
cp .env.example .env   # 按需填写微信小程序凭据
npm start              # 或 npm run dev（代码变更自动重启）
```

`.env` 变量说明：

| 变量 | 说明 |
|------|------|
| `PORT` | HTTP 端口，默认 3000 |
| `WS_PORT` | WebSocket 端口，默认 3001 |
| `MONGODB_URI` / `REDIS_URL` | 预留的持久化配置（当前未启用） |
| `WECHAT_APPID` / `WECHAT_APPSECRET` | 微信小程序凭据，用于昵称内容安全校验 |

> `.env` 含密钥，已被 `.gitignore` 忽略，请勿提交。

### 前端

用 HBuilderX 打开 `uniapp/` 目录：

- 调试：运行 → 运行到浏览器 / 微信开发者工具
- 上线：发行 → 小程序-微信

首次运行需在「游戏配置」页或 `uniapp/utils/config.js` 中填写后端服务地址。

## 游戏机制

| 阵营 | 人数上限 | 技能 | 目标 |
|------|---------|------|------|
| 🐱 猫猫 | 5 | 查看位置（Peek） | 抓住所有鼠鼠 |
| 🐭 鼠鼠 | 25 | 无（被动躲藏） | 坚持到时间结束 |

- 游戏区域：房主在地图上画圆确定范围
- 抓捕：猫猫靠近到设定距离内触发，有确认窗口
- 胜负：抓完所有鼠鼠则猫胜；时间耗尽则鼠胜

## 已知限制

- 数据存于内存，服务重启即清空，生产环境建议接入持久化数据库
- 玩家身份为客户端生成，正式上线建议接入微信登录获取真实 openId
